# STM32 智能环境监控系统

这是一个基于 STM32F103C8T6 的智能环境监控系统。系统通过 DHT11 (温湿度)、BH1750 (光照)、土壤湿度传感器实时监测环境，并支持通过串口指令或**云端物联网平台**配置水泵和蜂鸣器的自动控制规则。

## 🌟 最新特性 (New Features)
- **云端物联网支持**: 集成 ESP8266 Wi-Fi 模块，接入巴法云 (Bemfa) TCP 创客云，实现远程数据监控与控制。
- **实时监测**: 集成多种传感器数据采集（温度、空气湿度、光照强度、土壤湿度），并定时上传至云端。
- **动态阈值**: 支持通过本地串口或云端透传指令实时修改控制阈值。
- **断电保存**: 配置的规则自动保存至内部 Flash，重启不丢失。
- **强制控制**: 支持无视传感器数据的强制开关模式（本地/云端双控）。
- **抗干扰设计**: 针对水泵启动瞬间的电磁干扰进行了 `system_busy` 软件保护。

### 🚀 快速开始 (指令摘要)
- **查看规则**: `ls cmd`
- **设置规则**: `PUMP Soil 0 low 30 high 1` (当土壤湿度 0-30% 时开启水泵)
- **强制开启**: `PUMP 1` (或云端控制端发送 `on`)
- **复位自动**: `PUMP auto` (或云端控制端发送 `off`)
- **帮助信息**: `help`

## 📁 项目结构
- `Core/`: 核心源代码及驱动（包含传感器逻辑、USART 解析与 Wi-Fi 云端交互）。
- `Drivers/`: STM32 HAL 库及 CMSIS 驱动。
- `MDK-ARM/`: Keil MDK 工程文件。
- `*.txt`: 各类开发、接线与使用手册。
